# Simply Playful

Used for the page header only, embedded in `index.html` as a base64 WOFF2 data URI.

- **Designer:** Keithzo — https://www.1001fonts.com/users/keithzo/
- **Source:** https://www.1001fonts.com/simply-playful-font.html
- **Licence:** 1001Fonts Free For Personal Use (FFP) — see `1001fonts-simply-playful-eula.txt`

The licence permits this use: clause 2 names "recreational websites and blogs for
friends and family" as personal use, and clause 7 permits embedding into a personal
web app. Clause 5 permits format conversion, so the shipped WOFF2 was produced from
the original OTF with `fontTools` using conversion only — **not subsetted, not renamed,
no glyphs altered**, since clause 4 forbids modification.

If this font is ever wanted for anything commercial, a licence must be bought from
the designer first.
